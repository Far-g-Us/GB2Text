# 📥 Скачать GB2Text

Скачивайте GB2Text — инструмент извлечения и перевода текста из ROM —
только из официального источника.

> **Этот инструмент предназначен ТОЛЬКО для анализа файлов ROM, которые
> принадлежат вам на законных основаниях.** Читайте, извлекайте, переводите
> и вставляйте текст ТОЛЬКО в файлы ROM, которые вы создали самостоятельно
> (homebrew) или приобрели на законных основаниях и имеете право
> анализировать, — никогда не в файлы ROM, которые вы скачали или которыми

> файлы ROM.**

## 🗔 Windows

- ✅ **Windows 10/11** (64-bit) — автономный `GB2Text.exe` (Python не нужен)
- ✅ Портативный — запуск без установки, настройки в `%APPDATA%\GB2Text\`
- ✅ Поддержка DPI, протестировано на Windows 10/11

### [⬇️ Скачать GB2Text.exe (Windows)](https://github.com/Far-g-Us/GB2Text/releases/latest/download/GB2Text.exe)

*Сборок под Android/iOS нет. Официальный релизный канал — Windows.*

## 🐧 Linux / 🍎 macOS

Готовые бинарники для этих платформ в этом репозитории не публикуются.
Сборка из исходников (Python 3.11+):

```bash
git clone https://github.com/Far-g-Us/GB2Text.git
cd GB2Text
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py --gui             # графический режим
```
